# Mocap_tool for Blender

Ferramenta de captura de movimentos para animar modelos humanoides, utilizando MediaPipe e Blender,
desenvolvida para um trabalho de conclusão de curso, na área de Ciência da Computação (IFMG - Formiga).


## Tecnologias utilizadas
Blender 5.1.1
Python 3.14.4
C++ 15.2.0

(Desenvolvido inteiramente em ambiente Linux)


## Bibliotecas utilizadas
av 17.0.1
mediapipe 0.10.35
opencv-python 4.13.0.92
